## 保留不譯（維持英文/原文）
- 技術詞：`token`、`LLM`、`API`、`URL`、`ID`、`Full access`、`agent`（英文出現時）、`Cmd/Ctrl+Enter`、`Enter`、`tok/s`、`Git` 等。
- 中文語境下嘅「智能體」用繁體轉換；英文 `agent` 保留。
- **插件**：DSH 生態用語，保留「插件」唔使轉「外掛」。
- 佔位符 `{name}` `{count}` `{provider}` 等：**原封不動**。

## 一般規則
1. 先轉換字元（簡→繁），再做術語替換（用上表）。
2. 標點：保留原樣（全形逗號、句號、「…」省略號）。
3. 用字：**裡**（唔用 裏）、**為**（唔用 爲）、**說**（唔用 説）、**之後**（時間後）。
4. 短語語氣：台灣/香港慣用自然語，唔好逐字直譯簡體句法。
5. 校驗：完成後必須用 JSON parser 驗證輸出合法，且 key 數與輸入一致、`{佔位符}` 無遺漏。
